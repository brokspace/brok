# Engineering skills

Daily code work. Promoted: embedded in the `brok` binary and exported by
`brok skill export`.

## User-invoked

- **[ask-brok](ask-brok/SKILL.md)**: Ask which Brokspace skill, flow or command fits what you are trying to do.
- **[setup-brokspace](setup-brokspace/SKILL.md)**: Configure this repository for the skills (issue tracker, triage labels, docs layout). Run once per repo.
- **[grill-with-docs](grill-with-docs/SKILL.md)**: Get interviewed about a change until it is fully specified, while building `GLOSSARY.md` and ADRs.
- **[to-spec](to-spec/SKILL.md)**: Turn the current conversation into a spec and publish it to the issue tracker.
- **[to-tickets](to-tickets/SKILL.md)**: Break a spec, plan or conversation into tracer-bullet tickets with explicit blocking edges.
- **[implement](implement/SKILL.md)**: Build a spec or tickets test-first at agreed seams, closing with a review and a commit.
- **[triage](triage/SKILL.md)**: Move issues and external pull requests through the triage state machine and write agent-ready briefs.
- **[retro](retro/SKILL.md)**: After a session, suggest improvements to the agent's environment, most severe first.

## Model-invoked

- **[brok-context](brok-context/SKILL.md)**: Explore a codebase through the Brokspace index (`brok search`, `brok_search`) before reading files blindly.
- **[tdd](tdd/SKILL.md)**: Test-driven development with a red-green loop, one vertical slice at a time, at agreed seams.
- **[diagnosing-bugs](diagnosing-bugs/SKILL.md)**: Make the bug red, minimise, hypothesise, instrument, fix, and prove the fix with a regression test.
- **[code-review](code-review/SKILL.md)**: Two-axis review (standards and spec fidelity) with severity-ranked findings at `path:line`.
- **[pr](pr/SKILL.md)**: The shape of a pull request description: summary, evidence, risk.
- **[domain-modeling](domain-modeling/SKILL.md)**: Sharpen the shared language in `GLOSSARY.md` and record hard decisions as ADRs.
- **[write-shard](write-shard/SKILL.md)**: Build a Brokspace shard with `brok-sdk`: events, least-privilege manifest, testing, release.
- **[write-skill](write-skill/SKILL.md)**: Author a good skill, choose its invocation, test it and share it as a skill shard.
