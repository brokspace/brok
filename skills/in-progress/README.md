# In-progress skills

Beta skills live here: public on purpose so people can try them and give
feedback, but **not** embedded in the `brok` binary and not exported by
`brok skill export`.

To try one, copy its folder into your workspace's `.brokspace/skills/` (or
your agent's skills directory). Feedback goes in an issue that names the
skill and describes a real session where it helped or failed.

A skill graduates to `engineering/` or `productivity/` once it has been used
in real sessions, its invocation (user or model) is settled, and the router
[`ask-brok`](../engineering/ask-brok/SKILL.md) knows when to send people to it.

There are no skills in progress right now.
