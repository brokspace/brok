# Productivity skills

General workflow tools, not specific to code. Promoted: embedded in the
`brok` binary and exported by `brok skill export`.

## User-invoked

- **[grill-me](grill-me/SKILL.md)**: Get interviewed about a plan or idea, one question at a time, until every decision is made.
- **[handoff](handoff/SKILL.md)**: Compact this session into a handoff document so another agent or person can continue the work.

## Model-invoked

- **[grilling](grilling/SKILL.md)**: The reusable interview primitive behind `grill-me`, `grill-with-docs`, `triage` and `to-spec`.
