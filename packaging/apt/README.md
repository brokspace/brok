# Brokspace APT repository

Canonical endpoint: `https://apt.brokspace.org`

The official APT repository is generated by the manually triggered `Publish APT repository` workflow in `brokspace/brok`. The workflow downloads the latest stable `.deb` artifacts from the independent `brok` and `brok-agent` GitHub release streams, produces `Packages` indexes, signs `InRelease` and `Release.gpg`, and deploys the static repository to GitHub Pages.

## Supported architectures and runtime floors

| Architecture | CLI minimum glibc | Agent minimum glibc |
|---|---:|---:|
| `amd64` | 2.31 | 2.31 |
| `arm64` | 2.39 | 2.39 |

The Linux agent packages are built with vendored OpenSSL so they do not rely on a host OpenSSL SONAME. Package dependencies still include `libc6` and `libgcc-s1`.

## Client setup

```sh
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://apt.brokspace.org/brokspace-archive-keyring.asc \
  | sudo gpg --dearmor -o /etc/apt/keyrings/brokspace.gpg
echo "deb [arch=amd64,arm64 signed-by=/etc/apt/keyrings/brokspace.gpg] https://apt.brokspace.org stable main" \
  | sudo tee /etc/apt/sources.list.d/brokspace.list
sudo apt update
sudo apt install brok brok-agent
```

Only the public key is installed on client systems. The archive signing private key stays in the `brokspace/brok` GitHub Actions secrets.
